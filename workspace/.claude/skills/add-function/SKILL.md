Add a function to `stats.py` as described by the user: $ARGUMENTS

1. Read `stats.py` and `test_stats.py` to match the existing style.
2. Add the function with a short docstring (edit_file, not write_file).
3. Add at least one test to `test_stats.py`, including an edge case (empty input).
4. Run `python3 -m unittest` and make sure everything passes.
